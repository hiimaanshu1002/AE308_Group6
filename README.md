# AE 308/775 Control Design MATLAB Scripts (Group 6)

MATLAB codebase to generate all 13 analysis, design, and validation plots and print closed-loop verification metrics to the console.

## Prerequisites

* **MATLAB** (R2020a or newer required for `exportgraphics`)
* **Control System Toolbox** (`tf`, `feedback`, `margin`, `stepinfo`, `bode`, `nyquist`, `rlocus`)

## Quick Start

1. Clone or download this repository and open MATLAB in the repository root folder.
2. Run the master script in the MATLAB Command Window:
   ```matlab
   run_all_figures
